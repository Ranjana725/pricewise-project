# 💹 PRICEWISE – Smart Product Price & Deal Analyzer

**Know the real price before you buy.**

PRICEWISE is a smart shopping assistant designed to help customers make better purchasing decisions by analyzing product prices, comparing stores, and identifying genuine deals.

Instead of trusting advertised discounts, PRICEWISE aims to use historical price information, seasonal trends, and price comparisons to help users decide whether to **BUY NOW or WAIT**.

---

## 🚀 Project Overview

Online shopping platforms frequently advertise attractive discounts. However, customers often don't know whether the discounted price is actually the lowest available price.

A product may have been cheaper in previous weeks or months, and the same product may be available at different prices across multiple shopping platforms.

PRICEWISE aims to solve this problem by providing a centralized platform for product discovery and intelligent price analysis.

## 🎯 Problem Statement

- Advertised discounts do not always represent genuine deals.
- Customers cannot easily access long-term price history.
- Product prices vary across different e-commerce platforms.
- Customers often miss better buying opportunities.
- Seasonal price trends are difficult to identify manually.

## 💡 Our Solution

PRICEWISE aims to provide:

- Product search and discovery.
- Historical price analysis.
- Price comparison across supported stores.
- Sale and seasonal trend analysis.
- Deal Score from 0–100.
- BUY NOW / WAIT recommendations.
- Future machine learning-based price prediction.

## ✨ Current Frontend Features

- **Modern Dashboard:** Dark, trading-inspired interface.
- **Product Catalogue:** Browse sample products across different categories.
- **Search:** Search products by name or brand.
- **Category Filters:** Filter products by category.
- **Sorting:** Sort products by price and deal score.
- **Watchlist:** Save favourite products.
- **Product Details:** View additional information about selected products.
- **Responsive Design:** Designed for desktop and mobile devices.

## ⚙️ Installation & Setup

Follow these steps to run PRICEWISE locally.

**1. Clone the repository**

```bash
git clone https://github.com/Ranjana725/pricewise-project.git
```

**2. Navigate to the project folder**

```bash
cd pricewise-project
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open in your browser**

```text
http://localhost:5173
```
